## B1（P2，代码/资源问题）首屏 favicon.ico 404

- 页面：封面 #/（及任何整页首次加载）
- 前置条件：全新浏览器 profile 打开站点
- 步骤：打开 http://127.0.0.1:5184/#/
- 预期：无资源 404，或显式声明站点图标
- 实际：控制台出现一次 `Failed to load resource: the server responded with a status of 404 (Not Found)`；`curl -o NUL -w "%{http_code}" http://127.0.0.1:5184/favicon.ico` 实测返回 404。index.html 没有 link rel="icon"，仓库也没有 favicon 资源
- 证据：本次回归控制台捕获记录（仅此 1 条）；curl 复现输出
- 复现稳定性：稳定复现（每个全新会话的首个整页加载各一次）
- 影响：无功能影响，仅控制台噪音与缺站点图标；建议集成方补 favicon 或显式图标声明

## B2（P2，视觉观察项）课程页路由切换后 h1 显示黑色焦点描边

- 页面：各课程页（#/labs/line、#/labs/te 等）
- 前置条件：无
- 步骤：从目录点击进入任一课程页（或路由切换）
- 预期：浅色精致风格下标题区域不出现突兀黑色描边
- 实际：h1 因路由切换被程序化聚焦（tabindex=-1 + focus），默认 outline 显示为明显黑色方框，见截图
- 证据：390/04-lesson-line.png、390/12-reduced-motion-line.png、390/15-lesson-te.png、1024/16-lesson-tm.png 中标题外黑框
- 复现稳定性：稳定复现（每次进入课程页）
- 说明：程序化聚焦本身是路由无障碍的正确做法，是否保留描边或改用更柔和的 focus 样式由 Codex 判定；本任务不改样式
