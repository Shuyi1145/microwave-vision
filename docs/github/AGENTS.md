6. 公式使用本地KaTeX标准分式和上下标；图注位置与“上方/下方”指代必须对应实际图形。
7. 矩形波导默认20mm×10mm，方便手算验证，仍可调节；不假称这一尺寸是通用标准。
8. 保持工程结构示意的细节与质感，避免以两个色块或方框代替真实传输结构。结构图尺寸未经求解时必须说明为示意。
9. 使用课程PDF中核对过的场图，保留必要色标与场量；支持放大。静态课件图例和参数驱动的实时动画必须区分。
10. 热力图不要因不恰当上界而整体偏蓝。默认按当前截面完整周期峰值固定色标，可切换统一参考幅值；零场不强行染色，不逐帧拉伸。
11. 传输线默认用彩色表示瞬时电压绝对值，另保留红正白零蓝负选项。固定参考幅值为(1+|Gamma|)V+，不能无条件除以2，也不能把绝对值当成有符号电压。
12. 圆图拖动应使用局部禁止选文、阻止默认指针行为与捕获/释放；不全局禁止复制。
13. 用户允许调研网页动画技能或开源组件并实际美化。保持轻盈、克制、顺畅，以入场、切换和操作反馈为主；不添加干扰阅读的持续闪烁，不装饰性改变物理场动画。
14. 动效须支持系统减少动态效果偏好，键盘焦点与按钮可操作性保持正常；库本地安装，不依赖远程脚本、字体、账号或付费服务。

## 物理准确性

- 保持原圆图约定exp(+j*omega*t)，从负载向信号源为正；沿线Gamma顺时针转动。场模式采用exp(+j*omega*t-j*beta*z)。
- 被动阻抗R>=0、Z0>0且有限；开路用独立状态表示。明确均匀无损、理想导体、正实特性阻抗的适用范围。
- TE00非法；矩形TM两个索引均非零。TEM同轴为双导体结构，不宣称空心单导体支持非零TEM。
- 显式区分传播、截止点和倏逝区；不可传播时不输出伪造的有限传播速度。相速大于c不等于信息超速。
- 横向箭头、纵向底色、瞬时总场强度与有符号场分量必须对应真实公式；E/H各自归一化，不跨量纲比较。
- 课件电流图不能说成电压图；圆波导索引不能套到矩形波导。物理时间与演示相位区分，不把屏幕动画速度当成真实频率。
- 修改公式、单位、边界、坐标或归一化必须增加或更新有独立解析依据的测试。
