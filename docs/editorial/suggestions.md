# 文案修改建议清单（W3 文案清点）

本文件是建议清单，尚未应用到任何产品源码。每条包含编号、原文位置、现行原文、建议写法、理由与适用页面。
分类说明：一致性 = 同一对象在不同页面写法不同；重复 = 同一含义的说明多次出现；表达 = 语句、用词或符号可改进但未改变物理含义；待核对 = 疑似涉及物理或路由归属，需 Codex 判断后再改；白名单外 = 文件不在 W3 可改目录，仅提交建议。

按建议顺序：先消除真实重复与不一致，再做表达优化；不凑条数。

## 三、表达与疑似错字

### S-15 非法输入提示用词生硬
- 位置：src/main.tsx L52
- 原文：`请输入有限数值，R≥0、Z0>0，绝对值≤10^6。结果暂为占位匹配，请修正输入。`
- 建议：`请输入有效数值：R≥0、Z0>0，绝对值≤10^6。当前结果暂按匹配状态显示，请修正输入后继续。`
- 理由："有限数值"在中文里更像"数量有限"，实际含义是有限（finite）且有效；"占位匹配"不是通用说法，用户难以理解当前显示的是什么。
- 适用页面：圆图实验室参数面板。

### S-16 暂停按钮使用罗马数字二
- 位置：src/main.tsx L54
- 原文：`Ⅱ 暂停`
- 建议：改为标准暂停符号，或改为纯文字"暂停"。若坚持用符号，建议与"播放"使用同一套符号体系。
- 理由："Ⅱ"是罗马数字二，屏幕阅读器会读作"二"，与暂停含义无关；与课程页"暂停动画"的纯文字写法也不一致。
- 适用页面：圆图实验室波形面板。

### S-17 模式约束使用半角逗号
- 位置：src/Lessons.tsx L46
- 原文：`m,n 不同时为 0`
- 建议：`m、n 不同时为 0`
- 理由：中文语境下并列变量应使用顿号；同一处 TM 侧写作"m≥1 且 n≥1"，格式已经统一，仅 TE 侧用了半角逗号。
- 适用页面：TE 波与矩形波导。

### S-18 TE 主题目标句读法绕口
- 位置：src/courseContent.ts L6
- 原文：`理解 TE 并非磁场也横向，区分截止频率、相速与群速。`
- 建议：`理解 TE 只要求电场横向，Hz 可以不为零；并区分截止频率、相速与群速。`
- 理由：原句"并非磁场也横向"是否定嵌套，学生需要二次解析才能理解；建议句直接给出判据，不改变物理内容。
- 适用页面：实验室目录卡片、TE 课程页"本节目标"。

### S-19 空状态与结果提示未覆盖存储失败情形
- 位置：src/main.tsx L54（`还没有记录。完成一次诊断练习后，会自动保存分数与时间。`）、src/main.tsx L66（`本次结果已提交保存。查看下面的错因，回到实验室验证你的理解。`）

- 理由：代码中有明确的存储失败分支（"浏览器存储不可用，本次结果仅在当前页面保留。"），但成功路径的文案无条件说"会自动保存""已提交保存"，两者对不上。
- 适用页面：学习记录、诊断练习结果页。
